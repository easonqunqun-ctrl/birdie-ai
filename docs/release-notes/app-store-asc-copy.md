## 4. App 隐私问卷（勾选指引）

路径：ASC → **App 隐私** → **开始 / 编辑**。

### 4.1 是否收集数据？
选 **是，我们会从此 App 收集数据**。

### 4.2 建议声明的数据类型

| 数据类型 | 是否收集 | 用途勾选 | 是否用于追踪 | 是否关联用户 |
|----------|----------|----------|--------------|--------------|
| **联系信息 → 电子邮件地址** | 是（Sign in with Apple 可能提供隐藏/真实邮箱） | App 功能 | 否 | 是 |
| **联系信息 → 姓名** | 是（可选昵称/Apple 姓名） | App 功能 | 否 | 是 |
| **标识符 → 用户 ID** | 是（账号 ID / Apple sub） | App 功能 | 否 | 是 |
| **用户内容 → 照片或视频** | 是（挥杆视频） | App 功能 | 否 | 是 |
| **用户内容 → 其他用户内容** | 是（AI 对话文本、档案信息） | App 功能 | 否 | 是 |
| **使用数据 → 产品交互** | 是（分析次数、功能使用日志等） | App 功能、分析 | 否 | 是 |
| **诊断 → 崩溃数据 / 性能数据**（若有） | 是（若实际上传错误/性能日志） | App 功能 | 否 | 否或是（按实际） |
| **位置 → 精确位置** | **否**（除非已上线持续定位） | — | — | — |
| **位置 → 粗略位置** | 仅当「附近球馆」等已对用户开放时勾选；用途：App 功能；不追踪 | 按实际 | 否 | 是 |
| **购买项目** | 若 App 内已有订单/会员状态：是；用途：App 功能 | 按实际 | 否 | 是 |

### 4.3 用途说明要点
- **App 功能**：登录、出报告、AI 对话、训练打卡、会员履约  
- **分析**（可选）：改进产品（去标识/统计向）  
- **不要**勾选「第三方广告」「追踪」类，除非你们确实做了 ATT 广告追踪（当前没有）
