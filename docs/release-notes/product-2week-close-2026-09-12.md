### PP-08 · 只拍这 5 条（最少 3 条出门）

| 优先级 | drill_id | 为什么先拍 | 道具 |
|--------|----------|------------|------|
| 必拍 | `drill_weight_shift` | 业余最常见；无道具 | — |
| 必拍 | `drill_hip_rotation` | 对应髋滑 / 转不开 | 1 根杆 |
| 必拍 | `drill_towel_arm` | 对应抛杆 / 双臂失联 | 毛巾 |
| 有余力 | `drill_alignment_stick` | 瞄不准，片好拍 | 瞄准杆 |
| 有余力 | `drill_half_swing` | 节奏 / 半挥 | 7 号铁 |

规格对齐 [`drill-demo-video-revamp.md`](./drill-demo-video-revamp.md) §3.2：**竖屏 9:16、30–60s**。  
**本窗口允许手机成片**（1080p、口播字幕齐即可），不阻塞等 ¥11K–18K 制片。片尾固定一句：按文字步骤练，**同机位再拍给 AI 复盘**。

**上架**

1. 文件放到一目录，文件名=`{drill_id}.mp4`（可选 `{drill_id}_thumb.jpg`）
2. `bash scripts/drill-demo-videos/upload-aligned.sh <目录>` → MinIO `samples/drills/`
3. 产品看过画面与步骤一致后，**只把这几个 id** 写入 `DRILL_VIDEO_ALIGNED_IDS`
4. **禁止**把 Mixkit 旧片加回白名单；脚本会拒收清单外 id

**验收**

- [ ] 至少 **3** 个 id 在白名单；训练任务展开能播，且画面与步骤一致（产品 1 人签字）
- [ ] 未对齐 drill **仍不出现**视频卡
- [ ] 教练对话命中这 3 个关键词时出现示范片，其它关键词仍只有文字步骤

### PP-07 / PP-09 · 真机咬合（不改交互除非坏了）

## 五、C · App × Gofly 试点（PP-17 · 新）

依据：[`p2-on-course-gofly-vendor-questionnaire.md`](./p2-on-course-gofly-vendor-questionnaire.md) + 厂商回复（2026-09 已回收）。

| 已确认 | 含义 |
|--------|------|
| 无硬件可用 **业务 user_id** 当 guid | 试点不买设备 |
| **不支持微信小程序 / 无 REST** | 只做 **Flutter App** |
| 约 1460 场；洞距 / 果岭前中后 / 障碍 / 15 码切洞 | 字段够测距 + 手记分 |
| 试用一周；可指定 1–3 场验证 | 本窗口只签试用，不谈年框 |
| 不提供策略文案 / 自动 GIR | 应用层自己做；两周内 **不做** |

**两周只交付「能下场打开的最小切片」**

| 必须有 | 可以没有 |
|--------|----------|
| 选中 1 个试点球场 | 附近球场列表打磨 |
| 当前洞 + 标准杆 | 自动 FIR/GIR |
| 距果岭前 / 中 / 后（米或码，产品定一种并写死） | AI 荐杆 |
| 18 洞手记分（杆数），能回看本场 | 统计图表、差点、分享赛后海报 |
| 权限：定位说明文案 | 后台持续定位、手表 |

**验收（周五三选一，必须写进纪要）**

| 结论 | 条件 |
|------|------|
| **继续** | 试点场 tee 上码数肉眼合理；前 3 洞能切洞 + 记分；无硬件 user_id 鉴权成功 |
| **换源** | SDK 实际仍绑硬件 / 无洞图且测距不可用 / 授权不允许 App 试用 |
| **暂缓** | 试用 key 两周内拿不到，或本周无人能下场——**记下blocker，不改做小程序** |

**不验收**：App Store 提审、全国球场浏览、与练习场报告打通（那是下一窗口）。
